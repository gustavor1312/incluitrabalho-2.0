# IncluiTrabalho 2.0 — Streamlit

## Executar no Windows PowerShell

Dentro desta pasta, use:

```powershell
python -m streamlit run app.py
```

Se `python` não funcionar:

```powershell
py -m streamlit run app.py
```

Acesse o endereço local mostrado pelo Streamlit, normalmente http://localhost:8501.

## Voz
A nova versão possui leitura da página e reconhecimento de comandos de voz pelo navegador.
Use Google Chrome ou Microsoft Edge e permita o acesso ao microfone quando solicitado.
